# Análises

Nesta pasta serão armazenados os resultados e insights gerados com **NotebookLM** e outras ferramentas de inteligência artificial.

## Estrutura sugerida
- 📊 Relatórios → documentos com análises detalhadas
- 📈 Gráficos → visualizações de dados (mapas, tabelas, dashboards)
- 📝 Insights → observações e recomendações estratégicas

## Como usar
1. Salve aqui os arquivos de saída das análises (PDF, CSV, imagens, Markdown).  
2. Organize por subpastas se necessário (ex: `setor-tecnologia`, `setor-comércio`).  
3. Documente cada análise com um breve resumo para facilitar a consulta futura.
