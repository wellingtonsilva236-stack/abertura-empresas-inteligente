# Abertura de Empresas Inteligente

Este repositório organiza dados, análises e guias relacionados ao projeto de abertura de empresas de forma inteligente.

## Estrutura do Repositório
- 📂 dados → fontes e relatórios utilizados (IBGE, Sebrae, Reclame Aqui etc.)
- 📂 analises → resultados e insights gerados com NotebookLM
- 📂 guias → miniguia de estudo e glossário para apoiar a compreensão

## Objetivo
Centralizar informações e análises que apoiem decisões estratégicas sobre abertura de empresas, utilizando dados confiáveis e ferramentas inteligentes.

## Como usar
1. Consulte a pasta **dados** para acessar relatórios e fontes.
2. Veja a pasta **analises** para resultados processados e insights.
3. Use a pasta **guias** como apoio para termos e conceitos.
