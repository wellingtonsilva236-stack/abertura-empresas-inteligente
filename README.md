# Abertura de Empresas Inteligente

## 📌 Descrição
Projeto prático desenvolvido para a plataforma DIO que une estratégia contábil à análise geomercadológica orientada a dados.  
Com NotebookLM e IA, busca reduzir o risco de falência precoce de novas empresas, recomendando regiões ideais para abertura de negócios.

---

## 🎯 Objetivos
- Integrar dados socioeconômicos, segurança pública, acessibilidade e reputação empresarial.  
- Criar prompts estratégicos para análise no NotebookLM.  
- Documentar insights e recomendações em formato acessível no GitHub.  

---

## 📊 Fontes de Dados
- IBGE – Cidades@  
- Ministério da Justiça – Segurança Pública  
- Reclame Aqui  
- Google Maps  
- Sebrae – Estudos e Pesquisas  
- ESPM – CEAM  

---

## 🧠 Prompts Estratégicos
- “Quais fatores mais influenciam na escolha de uma região para abrir empresas?”  
- “Compare a reputação das empresas em um raio de 2 km na região X.”  
- “Quais oportunidades surgem em áreas com empresas mal avaliadas?”
