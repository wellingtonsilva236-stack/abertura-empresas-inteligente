# Fontes de Dados

Este documento reúne as principais fontes utilizadas no projeto **Abertura de Empresas Inteligente**.

## IBGE
- [Cidades@](https://cidades.ibge.gov.br/) → dados socioeconômicos por município
- [SIDRA](https://sidra.ibge.gov.br/) → tabelas estatísticas detalhadas

## Sebrae
- [Estudos e Pesquisas](https://www.sebrae.com.br/sites/PortalSebrae/estudos-e-pesquisas) → informações sobre micro e pequenas empresas

## Ministério da Justiça
- [Dados de Segurança Pública](https://www.gov.br/mj/pt-br/assuntos/seguranca-publica) → estatísticas de criminalidade e segurança

## Reclame Aqui
- [Reclame Aqui](https://www.reclameaqui.com.br/) → índice de confiança e reputação empresarial

---

### Como usar
1. Baixe relatórios e PDFs dessas fontes.  
2. Salve-os nesta pasta `dados`.  
3. Atualize este arquivo sempre que incluir uma nova fonte.
